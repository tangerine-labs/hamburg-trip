# Hamburg trip map

Interactive map of things to do in Hamburg: food, skate spots, history/ferry, games and music.

- **Live:** https://tangerine-labs.com/hamburg-trip/
- `index.html` – self-contained Leaflet + OpenStreetMap map (category toggles, distance-sorted list, GPS dot, directions links)
- `hamburg-trip.kml` – import into Google My Maps
- `places.json` – source data for both outputs
- `data-src/` – raw OSM/geocoding results used to place pins

Some pins are approximate (street-level geocodes); opening hours and seasonal notes are in each popup. Verify before travelling.
